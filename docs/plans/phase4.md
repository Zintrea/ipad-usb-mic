## ลำดับประมวลผลเสียง (ใน `MicServer.handle()` ทั้งหมด)
ไมค์ → ตัดเสียงรบกวน → ความดัง (gain) → EQ → reverb → limiter → ตัด ±1 → ส่ง
- reverb เขียนเอง (Freeverb) แทน `AVAudioUnitReverb` เพราะ AU ทำงานก่อน `handle()` ทำให้ตัดเสียงรบกวนกินหาง reverb
- ตัดเสียงรบกวนอยู่ก่อน gain เพื่อให้ค่าที่เรียนไว้ไม่เพี้ยนเมื่อเลื่อนความดัง
- ไฟแดงค้างวัดหลัง reverb ก่อน limiter

## A1 `feat/eq-reverb`
- `Dsp.swift`: biquad high-pass + peaking (เพิ่มความใส 4 kHz), reverb แบบ Freeverb (comb 8 + allpass 4)
- หน้าหลัก: reverb ไม่มี / ห้อง / ฮอลล์
- ตั้งค่า: EQ เปิด/ปิด, ตัดเสียงต่ำ 60-200 Hz (100), เพิ่มความใส 0-6 dB (3), ปริมาณ reverb 0-50% (20)

## A2 `feat/noise-profile`
- FFT 512 / hop 256 (Accelerate) ลบแบบ spectral subtraction จำกัดความลึก ดีเลย์เพิ่ม ~11 ms
- หน้าหลัก: สวิตช์ + ปุ่ม "เรียนเสียงรอบข้าง" นับ 3 วินาที, จำ profile ข้ามการเปิดแอป
- ตั้งค่า: ความลึก 0-20 dB (10)

### ปรับแต่งตัดเสียงรบกวน `feat/noise-tune` (แตกจาก `feat/pc-monitor`, 2026-10-18)
- เหตุผล: ผู้ใช้เทียบกับ ReaFIR (Subtract, FFT 4096-16K, เรียน 30-60 วินาทีโดยขยับตัว/หายใจ/ลากเก้าอี้เพื่อให้ตัดเสียงเหล่านั้นด้วย) ของเดิม (FFT 512, เฉลี่ยอย่างเดียว, ลึก 10 dB) สู้ไม่ได้
- FFT เลือกได้ 1024 / 4096 (เริ่มต้น) / 16384 ดีเลย์เท่าขนาด (21 / 85 / 341 ms) เปลี่ยนได้ตอนหยุดอยู่เท่านั้น profile จำแยกตามขนาด
- profile = ค่าเฉลี่ย + ความไว × ส่วนเบี่ยงเบนของแต่ละความถี่ (ไวเริ่มต้น 2, ปรับได้ทันทีไม่ต้องเรียนใหม่)
- เวลาเรียน 3-60 วินาที (เริ่มต้น 30) ความลึก 0-30 dB (เริ่มต้น 20)
- ตัวรับ log เตือนเมื่อหูฟังที่ฟังเสียงตัวเองเป็นบลูทูธ (ดีเลย์ 100+ ms แก้ด้วยซอฟต์แวร์ไม่ได้)
