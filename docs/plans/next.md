## ฟีเจอร์ที่ผู้ใช้ต้องการคุยต่อ (ยังไม่ออกแบบ)
- ฟังเสียงตัวเองผ่านหูฟัง (ทำฝั่ง Windows ได้) ต้องดู latency ไม่ให้รบกวนการร้อง
- reverb และ EQ
- ตัดเสียงรบกวนแบบ "กดเรียนเสียงรอบข้าง (noise profile) แล้วตัดเสียงนั้นออกตอนใช้งาน" ผู้ใช้เคยทำใน OBS ได้ผลดี
- ตัวรับเปิดเองตอนเปิดคอม (แตะการตั้งค่า Windows ต้องเป็นแผนแยก)
- รอบหน้าตามที่ผู้ใช้สั่ง: limiter กันเสียงแตก, ไฟแดงค้าง 2 วินาทีเมื่อ clip
- ไม่ทำ (ตัดสินแล้ว): ฟังเสียงตัวเองผ่านลำโพง iPad (latency สูง)

## ข้อกำหนดการออกแบบจากผู้ใช้
- ใช้ง่ายที่สุด: เสียบสาย → เปิดแอป → START ใช้ได้เลย ห้ามแก้ด้วย option ที่ต้องพิมพ์ ให้เป็นค่าอัตโนมัติหรือปุ่มในแอป
- ผู้ใช้ไม่ชอบ OBS เพราะใช้ยาก ไม่เข้าใจ และบางครั้งทำงานไม่ตรงที่คิด (ตัวอย่าง: ตัดเสียงรบกวนแล้วไม่ได้ผลตอนใช้จริง) ฟีเจอร์เสียงใหม่ต้องมีค่าเริ่มต้นดี ปุ่มน้อย ผลฟังออกทันที
- คุณภาพเสียงดีที่สุด latency ต่ำ (ตอนนี้ iPad 7-9 ms + buffer 30 ms + WASAPI low)
- ผู้ใช้ร้องเพลงและเล่นกีตาร์ เสียงดังมาก (กังวลเรื่อง clip)
