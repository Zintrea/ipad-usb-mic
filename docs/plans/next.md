## วิเคราะห์ไฟล์เทียบ (ผู้ใช้ให้ฟังเองไม่ได้ ใช้ตัวเลขแทน)
- เครื่องมือในเครื่องแล้ว: Python ระบบ (`python`) มี numpy + matplotlib, ffmpeg อยู่ใน PATH; `windows\.venv` มีแค่ numpy ไม่มี matplotlib/scipy/soundfile (ติดตั้งแพ็กเกจต้องขออนุมัติแยก)
- `.m4a` = AAC: ffmpeg แปลงสำเนาเป็น WAV 48 kHz mono ในโฟลเดอร์ชั่วคราว ไม่แก้ไฟล์ต้นฉบับ เชื่อถือย่านต่ำกว่า ~15 kHz เท่านั้น (AAC ตัดย่านสูงและเติมสัญญาณรบกวนตอนบีบอัด)
- ตัวชี้วัด: ระดับเสียงรบกวนช่วงเงียบแยกย่านเทียบไฟล์ดิบ, ความต่างของเสียงร้อง (ย่านไหนเบาลง/เพี้ยน), การตัดเสียงขยับตัว/หายใจ, ความผันผวนของสเปกตรัมช่วงเงียบ (เสียงในน้ำ), ภาพสเปกโตรแกรมเทียบกัน
- ReaFIR ที่ผู้ใช้ใช้ใน OBS: Subtract, FFT 4096 (บางครั้งถึง 16K), เรียน 30-60 วินาทีโดยขยับตัว/หายใจ/ลากเก้าอี้เพื่อให้ตัดเสียงเหล่านั้นด้วย (ภาพตัวอย่างไม่ใช่ค่าจริง)
- ผลใน Python (เสียงสังเคราะห์ ไม่ใช่ห้องจริง) อยู่ใน LOG ข้อ feat/noise-tune; สคริปต์ทดสอบเดิมอยู่ใน scratchpad ของเซสชันก่อน (หายได้ ไม่อยู่ในโปรเจกต์)
- สิ่งที่ยังไม่ได้ลองใน ci10: ReaFIR ทำ per-bin smoothing/ปรับโค้งเอง, subtract factor เดิม 2 เท่าอาจไม่เหมาะ, ไม่มี noise gate หลังตัด

## ข้อเท็จจริงเรื่องหูฟังและดีเลย์
- หูฟังที่ผู้ใช้ใช้ฟังเสียงตัวเองคือ SIBYL X-1035 เป็นบลูทูธ (เจออุปกรณ์ Hands-Free ของ `bthhfenum.sys` ชื่อรุ่นเดียวกัน) ดีเลย์ 100+ ms ซอฟต์แวร์แก้ไม่ได้ จึงได้ยินเสียงตัวเองซ้ำตามหลัง ฟังเสียงตัวเองเรียลไทม์ต้องใช้หูฟังสาย (ประมาณ 40 ms ยังไม่ได้วัด: iPad 5 + ตัดเสียง + limiter 1 + jitter 10 + WASAPI 22)
- ตัดเสียงรบกวน FFT 4096 เพิ่มดีเลย์ 85 ms (1024 = 21 ms, 16384 = 341 ms)
